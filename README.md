# Minesweeper

I made a game of minesweeper using Java and core libraries from [Processing](https://processing.org/). I took inspiration for some of my visuals for Google’s [Minesweeper](https://www.google.com/fbx?fbx=minesweeper). I was able to further my project by allowing players to rescale the board in real time using the up and down arrow keys to increase or shrink the board size of 5 x 5 tiles to 50 x 50 tiles with the number of bombs scaling appropriately to ensure consistante difficulty. This project taught me a lot about Java and understanding the applicability of a programming language given the scale of the task at hand.
